# 区域验收历史边界

本目录保存从公共区域验收规格迁出的、已脱敏的历史执行叙述、缺陷发现过程和
覆盖审计。保留这些文本是为了追溯用例为何变化，不是为了声明当前 release
已经通过。

- 当前测试步骤和判定：`docs/区域模式端到端验收测试用例.md`
- 当前机器可读 verdict：`testcases/fault-scenarios.yaml`
- 原始 JSON、日志、真实时间和资源标识：受控私有证据库或 CI artifact

这里的历史日期、旧节点、旧 Profile、旧摘要和 PASS/BLOCKED 结论都不得直接
复制回公共规格，也不得作为新 release 的验收证据。新增历史内容必须先脱敏，
并按用例 ID 关联。
